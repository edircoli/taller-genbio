# Taller: Introducción a los modelos generativos en biología

Material del taller para estudiantes de primer y segundo año de licenciatura.

## Abrir el notebook

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/edircoli/taller-genbio/blob/main/notebooks/taller_fava.ipynb)

No necesitas instalar nada: el notebook corre en CPU y descarga los datos solo.

## Contenido

- `notebooks/` — notebook principal (VAE sobre células y sobre genes)
- `slides/` — presentación teórica
- `figuras/` — figuras generadas

## Datos

PBMC 3k (10x Genomics), vía `scanpy.datasets.pbmc3k_processed()`.
